# Keywords

This folder contains keyword lists and query templates for US market crawling.

## Conventions
- One keyword per line in aw/*.txt
- Lines starting with # are comments
- queries/en/compiled/*.txt are final query lists consumed by the crawler

## Lanes
- fast_lane_queries.txt: high-frequency sources (social posts, breaking news)
- slow_lane_queries.txt: low-frequency sources (macro releases, earnings)
